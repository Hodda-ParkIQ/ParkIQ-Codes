# ParkIQ 차량용 UI 1.3

## 참고한 공식 자료

- [현대차 ccNC 지도 화면](https://ownersmanual.hyundai.com/ivi/ccNC/AVNT/KOR/Korean/Map.html): 지도와 검색 목록의 분리, 선택 항목 강조, 하단 주요 조작 배치.
- [현대차 ccNC 주변 시설 검색](https://ownersmanual.hyundai.com/ivi/ccNC/AVNT/KOR/Korean/Map_poicategories.html): 결과 목록과 지도 간 대응, 목적지 설정 및 경유지 동작의 명확한 구분.
- [Pleos Connect 공식 화면](https://pleos.ai/service-solution/pleos-connect?locale=en-US): 밝은 바탕, 절제된 색상, 간결한 지도 조작 및 정보 위계.
- [Pleos UI Design Guide](https://document.pleos.ai/docs/connect/guide/docs-design/Introduction/intro): 짧은 시간에 읽을 수 있는 핵심 정보, 큰 터치 영역, 높은 대비, 짧은 문구, 주야간 가독성.
- [Pleos Typography](https://document.pleos.ai/en/docs/connect/guide/docs-design/foundations/typography): 중립적인 서체와 정보 위계. 가이드에 소개된 Asta Sans를 사용.
- [Pleos 지도·내비게이션 앱 가이드](https://document.pleos.ai/en/docs/pleos-only/vehicle-app-developer-guide/navigation-app-development-guide): 주행 중 긴 목록 스크롤 및 전체 화면 팝업 제한, 음성과 단일 터치 중심 조작.

2026-11-09에 확인했습니다. 참고 화면의 배치 원칙을 ParkIQ에 적용했으며 현대차의 공식 앱이나 인증된 UI를 의미하지 않습니다. 실제 현대차 화면 이미지·로고·전용 서체는 제품에 포함하지 않았습니다.

## 화면 구성

1. 상단: 앱 이름, 현재 시각, 시연/실데이터 구분, 주행 제한 상태, 주야간 전환, 설정.
2. 왼쪽: 목적지, 주변/즐겨찾기/최근 안내 탭, 정렬과 충전 조건, 주차장 목록.
3. 오른쪽: 위치 비교 지도, 선택한 주차장 이름·도보 거리·요금·잔여 상태, 안내 시작.
4. 하단: 음성 검색, 안내 음소거, 이용 안내. 안내 시작과 음성 검색의 위치를 유지.

광고성 문구와 영어 슬로건을 제거하고 주차장 이름, 도보 거리, 잔여 면수, 예상 요금을 우선 표시합니다. 흰색/회색 바탕에 파란색으로 선택과 주요 행동을 강조합니다. 야간 화면에서는 어두운 중성색 바탕과 밝은 글자로 전환합니다. 주야간 전환은 사용자의 수동 설정이며 차량 조도와 자동 동기화하지 않습니다.

## 운전 중 조작

- 한 화면에 최대 3곳, 720px 높이에서는 2곳, 더 낮은 창에서는 1곳을 표시합니다. 이전/다음 버튼으로 이동하며 결과 목록 자체를 길게 스크롤하지 않습니다.
- 목록 페이지를 바꾸면 해당 페이지의 첫 주차장을 미리 선택합니다. 실제 내비게이션 요청은 안내 시작을 눌러야 전송됩니다.
- 지도에는 해당 페이지의 주차장만 표시합니다. 가까운 표식은 위치 점과 연결선을 사용해 겹침을 줄입니다.
- 주행 제한 상태에서는 키보드 검색·설정·최근 기록·즐겨찾기 편집·지도 확대/축소를 제한합니다. 저장한 주차장 선택과 안내 시작, 음성 검색은 유지합니다.
- 주행 중 음성 검색은 전체 화면을 덮지 않는 패널을 사용합니다. 세로 창에서도 안내 시작 버튼을 가리지 않도록 배치합니다.
- Android 호스트는 `CarUxRestrictionsManager`를 우선 사용하며, 해당 상태가 없을 때 속도 정보로 간편 모드 여부를 판단합니다. 두 정보가 없으면 입력 제한을 유지합니다.
- 차량 서비스 연결은 기다리지 않는 콜백 방식입니다. 음성 패널을 닫거나 앱이 백그라운드로 이동하면 Android 음성 인식을 취소합니다.

## 서체와 크기

Asta Sans 가변 서체를 로컬 WOFF2로 제공합니다. UI를 표시할 때 외부 폰트 서버에 접속하지 않습니다. 원본은 [Google Fonts Asta Sans](https://github.com/google/fonts/tree/main/ofl/astasans)이며 [OFL 라이선스](../frontend/public/fonts/OFL.txt)를 함께 포함합니다.

주차장 이름과 목적지, 도착 시간은 본문보다 크게 표시합니다. 1280×720 검증에서 안내 시작, 음성 검색, 목록 선택, 주요 탭, 지도 버튼, 저장 버튼의 터치 영역이 최소 48×48 CSS px임을 확인했습니다. 물리적인 화면 크기·DPI와 운전자 거리에서의 가독성 검증 및 Pleos 심사를 대체하지 않습니다.

## 검증 범위

`scripts/check-ui.py`로 페이지 전환, API 정렬·필터, 저장 유지, 목적지·주차 시간 변경, 주야간 설정 유지, 주행 제한, 부분 음성 패널, 안내·취소·기록, 오류 복구, 모의 차량/Gleo 계약을 검증합니다. 1440×1080, 1280×720, 390×844의 정차/주행 상태를 확인합니다.

지도는 기존과 동일하게 시연용 개략도입니다. 차량 속도·방향 전환 지시·공조 상태 등 실제로 연결하지 않은 차량 정보를 화면에 만들어 표시하지 않습니다. 실제 경로 안내는 연결된 차량 내비게이션이 수행합니다. 새 Android 주행 제한 및 음성 취소 연동은 컴파일을 확인했으며 현재 연결된 Pleos 장치가 없어 실제 차량 서비스 이벤트는 재검증하지 못했습니다.


## 1.3 테스트 위치와 검증 범위

정차 상태의 브라우저와 디버그 APK에서 설정 → 테스트 위치로 좌표 입력, 성수/서울숲/종로 프리셋, 지도 클릭, 차량 마커 드래그를 지원합니다. 위치만 변경하는 행동과 해당 위치 주변 주차장을 검색하는 행동을 분리합니다. 테스트 좌표 활성 중 차량 GPS가 좌표를 덮어쓰지 않으며, GPS 위치로 복귀로 해제합니다. 주행 제한 중에는 위치 선택을 취소하고 편집을 막습니다. 릴리스 APK에서는 이 테스트 기능과 저장된 테스트 좌표를 사용하지 않습니다.

지도는 현재 OpenStreetMap/Leaflet 기반이며 타일은 네트워크가 필요합니다. 지도 조작부의 레이어는 지도 캔버스 안에 격리하고 테스트 도구는 지도 아래 별도 행으로 배치해 마커와 설정 창을 가리지 않게 했습니다. 마커를 드래그하는 도중 시계 갱신 때문에 마커가 교체되지 않도록 데이터 참조를 유지합니다.

가이드의 전 항목 준수 검증이 완료된 것은 아닙니다. 수동 주야간 전환, 일부 색상 대비와 물리적 글자 크기, 공식 컴포넌트 치수 및 다양한 Pleos 창 배치는 추가 보완 대상입니다. 브라우저의 주요 조작 테스트 통과를 Pleos 공식 디자인 심사 통과로 해석하지 않습니다.
